📲 安装步骤

  1. 点击上方「下载」按钮，把 拾音-ShiYin-x.x.x-release.apk 存到手机（微信/QQ 发的也行）。
  2. 在手机上点开 APK，按提示允许「未知来源」安装。
  3. 首次打开会申请通知权限——同意才能看到通知栏播放控制（拒绝也能正常播放）。
  4. 想听手机里的歌：到「设置 → 音源 → 本地音乐 → 授权并扫描」。
  5. 想接网盘 / 自建服务器：到「设置 → 音源」按提示填地址与账号。

推荐安装 release 包（不可调试、体积更小）。另有 debug 包含调试信息，仅在需要抓日志排错时使用。

🔄 开启自动更新

  1. 打开 App，进入「设置 → 更新」。
  2. 把「更新源地址」填成下面这行目录（注意：只填到 main，不要带 /update.json，App 会自动补）：

https://raw.githubusercontent.com/yyx82717/shiyin/main

国内访问 raw.githubusercontent.com 偶尔不稳，可改填 jsDelivr 镜像（更稳）：
https://cdn.jsdelivr.net/gh/yyx82717/shiyin@main

  1. 打开「启动时自动检查」。
  2. 以后只要在 GitHub 发布新版（Releases），并把仓库里的 update.json 同步改好，App 启动就会自动发现更高版本并提示下载——绝不静默安装。（App 已兼容「填目录」和「填完整文件路径」两种写法，二选一即可。）

update.json 已在仓库根目录：发版时把里面的 versionCode、versionName、apk（填新版 release 资源的完整 URL）、notes、size、sha256 改好再提交即可。带 sha256 时 App 会严格校验，下错或被篡改直接拒装。

⚙️ 系统要求

  • Android 7.0（API 24）及以上。
  • 拼音搜索依赖系统 ICU 音译器（Android 10+），更老的系统只是少这一项，其它照旧。
  • 连接自建 / 网盘音源需要对应服务器或账号。
  • 无需 Google 服务，纯离线也能播本地与已下载的歌。

🛠️ 自己编译

  • 命令行：bash tools/build_apk.sh assembleRelease（本机工具链已配好）。
  • 或用 Android Studio 打开工程直接 Run（需 Android 14/15 SDK）。
  • 详细说明见仓库 README 的「自己重新编译」一节。
  • 上架应用商店前请换成你自己的签名（release 目前复用 debug 签名，方便直接安装）。
