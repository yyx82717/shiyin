CORE

一个播放器，装下你所有的音乐

从搜得到、放得稳，到听得爽、更新省心，拾音把分散在各处的曲库真正打通。

五源合一的曲库

本地 / 百度网盘直连 / Subsonic 自建 / WebDAV 网盘 / 开放曲库，一次搜索跨所有源，结果分区标注来源。

后台与锁屏播放

基于 Media3 MediaSession，退后台、锁屏、切 App 都不中断；通知栏与锁屏完整控制，来电或拔耳机自动暂停。

专业播放内核

10 段均衡器（31Hz–16kHz）、0.75–2.0× 变速不变调、睡眠定时、淡入淡出，自研 PCM 处理器不依赖设备自带。

歌词全都要

逐字高亮、双语对照、TTML，本地同名 .lrc 自动读取，在线搜不到还能直接粘贴 LRC，跟着唱不漏字。

聪明的播放

待播队列、拼音搜索、搜索历史、接着上次听、播放失败自动跳过——用过就回不去的细节。

装好就更新

设置里填一个「更新源地址」，应用启动自动检查，发现更高版本才提示下载——绝不静默安装。

SOURCES

五条合法音源通路

不抓取 QQ 音乐 / 网易云 / 酷狗，而是把「你本来就有权听」的音乐，用合规方式统一进来。

本地

本地音乐

手机里所有 mp3 / flac / m4a / wav / ogg / ape，一次授权即可扫描；结果落盘快照，重开即出。

百度

百度网盘 · 直连

读你自己的网盘音乐目录，不需要 AList、不需要任何设备常开。手机就是客户端，整条链路无中间服务器。

自建

自建曲库（Subsonic）

你自己的完整收藏，放在 NAS / 树莓派 / 电脑上。填服务器地址 + 账号密码，密码不随请求发出。

网盘

网盘音乐（WebDAV）

坚果云、Nextcloud、群晖，或用 AList 把阿里云盘 / 夸克 / OneDrive 挂进来，填目录地址即可。

开放

Audius / Jamendo

开放授权曲库，无需任何配置，内置曲风推荐。只播你搜到的，不抓取任何商业平台音频。

为什么不去「抓取全平台」？

抓取 QQ 音乐 / 网易云 / 酷狗的音频，属于绕过技术措施 + 侵犯信息网络传播权，非商业用途也不构成豁免。 拾音选择另一条干净的路：本地库、你自己的网盘、自建服务器、开放曲库——这五条都是你本来就有权的音乐。 搜不到的歌，只提供「跳到官方平台去听」的入口，绝不下载任何受版权保护的音频。

FAQ

常见问题

要钱吗？+
完全免费，开源（Apache-2.0）。没有内购、没有广告、没有会员墙。
支持哪些音源？+
本地音乐、百度网盘直连、自建 Subsonic 曲库、WebDAV 网盘（AList 等）、以及 Audius / Jamendo 开放曲库，共五类。详见上方「音源」一节。
百度网盘需要一直开电脑吗？+
不需要。百度网盘走的是官方直连通道，手机就是客户端，读的是你自己的网盘目录，没有任何需要常开的服务器（和 WebDAV 不同）。
安装时提示「未知来源」？+
这是 Android 的常规安全提示，因为安装包不是从应用商店来的。到设置里允许本次安装来源即可，应用本身不含任何越权行为。
以后更新方便吗？+
方便。在「设置 → 更新」里填好更新源地址（本仓库的 update.json），应用每次启动自动检查，发现更高版本才弹窗提示，绝不强装；带 sha256 时严格校验，篡改直接拒装。
我的账号密码安全吗？+
Subsonic / WebDAV 的密码只存在应用私有目录（DataStore），不上传任何服务器；百度授权走官方 OAuth 页面，密码不经过 App。
